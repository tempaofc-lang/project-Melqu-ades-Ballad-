# 第二十五章

【第谷基地·社区公共讨论平台·凌晨】

第一例死亡案例出现在地球时间周三的凌晨。

联邦卫生应急委员会的官方声明在事发六小时后发布，措辞经过了显而易见的反复斟酌——"首例因记忆功能性丧失引发继发性系统衰竭的病例"，没有用"死亡"，没有用"致死"，用的是"衰竭"。声明的最后一段强调，这一案例属于极端个例，当前研究进展稳定，联邦卫生系统正在全力应对。

然后，第谷的公共讨论平台开始热闹起来。

发帖人的账号显示是新上海区居民，职业标签是结构工程师，在第谷住了五年。帖子的标题很简单："我想把我父母接上来，有人知道现在的流程吗？"

到早上七点，这条帖子的回复数量超过了两千四百条。

第谷的公共讨论平台是一个半开放的系统，各分区居民都可以访问，Metis会对热度异常的帖子进行实时追踪并生成摘要，推送给相关的社区协调员。早上六点五十三分，Amara的终端收到了这份摘要，她正在刷牙，单手点开，把摘要扫了一遍。

她把牙刷放下，把摘要重新看了一遍。

回复里的声音大致分成几个方向。

有人说当然要接，现在地球上的情况已经不是正常的卫生事件了，出现了死亡案例，这意味着它会要人命，把家人留在那里是不负责任的。有人说接不了，第谷的入驻资质审核不是走流程就能绕过去的，普通家属随迁需要主申请人达到一定的资历门槛，紧急通道需要联邦级别的授权，不是你想接就能接。有人说即使能接，也不应该接，月球现在是安全的，是因为它和地球之间有足够的物理隔离，如果大量地球人涌进来，谁能保证这种隔离还有效？

最后这种声音是最让Amara停下来的。

她在评论区里找到了那条原始回复，发帖人是一个神经科学方向的研究员，措辞很谨慎，没有下结论，只是提出了一个问题：记忆缺失事件的传播路径目前尚不明确，在机制未知的情况下，是否应该限制地球人员大规模入驻月球基地？

这条回复下面，有人赞同，有人愤怒，有人说这是歧视，有人说这是科学谨慎，有人说你的父母也在地球上，你说这话良心不会痛吗。

讨论在两千四百条回复里没有任何共识，只有越来越重的情绪。

Amara把手机放在洗手台边缘，对着镜子看了自己一秒钟。

然后她把牙刷重新拿起来，把剩下的牙刷完，洗脸，换衣服，出门。

【第谷基地·新上海区·居住舱B-17层】

郑永年是在早饭时间看见那条帖子的。

准确来说，是许栀先看见的，然后把终端推到他面前，没有说话，只是看着他。

他把那条帖子和前一百条回复看完，然后把终端推回去，继续吃饭。

"你怎么想？"许栀问。

"我在想。"他说。

许栀没有继续追问。她知道他不是在敷衍，是真的在想。这是郑永年处理困难问题的方式，他不会在想清楚之前开口，有时候这个过程需要几个小时，有时候需要几天。

郑雨棠没有在饭桌上，她昨晚在图书馆待到很晚，今天早上起得迟。郑永年从卧室方向听见了她翻身的声音，然后是开灯的声音，然后是她对着终端喃喃自语说今天几点有课的声音。

他看着面前的粥，想到了他父亲。

他父亲今年六十七岁，腿脚还算利索，但有高血压，每天早上要吃两种药。他母亲六十四岁，身体比父亲好，但不太会用新版的通讯软件，每次视频通话都要让父亲帮她调界面。他们住在东南沿海的老城区，小区的楼道灯坏了好几年，物业一直没修。

郑永年想，如果他要把他们接上来，流程是什么。

他把这个问题扔给Metis，让它搜索当前有效的家属随迁申请渠道。

Metis给出的答案是标准的。家属随迁需要主申请人在第谷工作满五年以上，持有有效的专业技术资质证书，且家属年龄需在十八至六十岁之间。六十岁以上的老人入驻需要额外的医疗评估和特殊审批，审批周期为九十个工作日起。

郑永年盯着"六十岁以上"这一行看了很久。

他父亲六十七岁，母亲六十四岁。

九十个工作日，差不多是四个半月。

他把终端放下，把那袋粥喝完了。味道他没尝出来是什么。

【第谷基地·信息协调署·Amara办公室】

上午十点零八分，Amara的终端亮了，是一份政府文件。

发件方是第谷基地行政长官办公室，文件编号是一串标准的联邦行政代码，正文不长，措辞是那种每个字都经过反复权衡之后的结果——平稳，周全，没有任何一个词可以被单独抽出来质疑，但整体读下来之后，意思非常清楚。

文件的核心内容分两部分。

第一部分：鉴于当前地球神经系统卫生事件持续发展，联邦政府高度重视月球基地的运营稳定性，要求各基地严格执行现行入驻资质审核标准，不得在未经联邦授权的情况下启动大规模人员转移程序，以确保基地生命保障系统和社会秩序不受冲击。

第二部分：各基地应积极响应居民的合理人道主义关切，做好信息沟通和情绪疏导工作，维护社区稳定，确保基地正常运营不受舆论波动影响。

Amara把这份文件读了三遍。

第一遍之后，她明白了联邦在说什么。

第二遍之后，她明白了联邦没有在说什么。

第三遍之后，她打开了一个新的工作文档，开始起草今天下午全员信息通报的草稿。

文件要求她维持审核标准，同时要求她安抚居民情绪。这两件事在现在这个时间节点上不是并列关系，而是正面冲突的关系。维持标准意味着大多数想把家人接上来的居民会得到一个否定的答案，而在第一例死亡案例出现之后，任何形式的否定都会被情绪放大成一种冷漠甚至残忍。

她在草稿的第一行写了一句话，然后删掉了。

又写了一句，又删掉了。

第三次，她写下："关于近期家属随迁申请的说明。"

然后她开始填充内容，一段一段，把那份联邦文件的意思用一种更接近人话的方式重新包装，同时确保每一句话都在她被授权说的范围之内。

这个过程让她想起她在地球上读研究生时做过的一份兼职，在一家律所整理案件档案。律师告诉她，最难写的不是结论，而是那些你知道答案但不能直接说出口的部分，你需要用足够精确的语言把那个答案的轮廓描绘出来，让对方自己看明白，同时你没有说谎。

她当时觉得这是一种很奇怪的技能。

现在她在用它。

【第谷基地·新伦敦区·公共休息廊】

公共休息廊里有一场没有被组织过的讨论。

它是自发形成的，从中午开始，有人坐在那里刷那条帖子，然后有人坐过来，然后又有人坐过来，到下午两点的时候，那片区域已经聚集了十来个人，来自至少四个不同的分区，然后就开始。

没有人主持，没有议程，就是在说话。

一个来自新纽约区的女性医疗工程师说，她丈夫在地球上的医院工作，最近已经开始接触失忆症患者了，她不知道接触是不是安全的，她不知道他知不知道自己在面对什么。

一个来自新上海区的男人说，他父母不愿意上来。他问过了，他们说月球太远，说他们这把年纪了不想折腾，说地球上的事情没有那么严重。他说他不知道该怎么办，劝不动，也没有办法代替他们做决定。

一个来自新莫斯科区的年轻工程师说，他觉得现在讨论接不接家人是一个伪命题，真正的问题是那个神经科学研究员提出的问题——如果来源不明，传播路径不清楚，月球现在的安全是因为隔离，那隔离是否应该维持？他说这话时语气很平，不是在攻击谁，但休息廊里的空气变得有点硬。

医疗工程师抬起头，"你的意思是不让我丈夫上来？"

"我的意思是这是一个需要回答的问题。"

"这不是一个抽象的问题。"

"但它是一个真实的问题。"

两个人对视了几秒钟，没有继续争下去。

旁边有人低着头，一直没有开口。他是来自新非区的一名数据分析员，来第谷三年，家里还有父母、一个弟弟和弟弟刚出生六个月的孩子。他今天早上发出了随迁申请，Metis给他返回的是标准的受理通知，预计审核周期九十个工作日起。

他没有说这件事，只是坐在那里，听别人说话。

窗外，月球地表的光线正处于人工白昼的中段，明亮、均匀、没有任何阴影。

【月背·广寒宫·通讯控制室】

林晓冬在下午的例行校准结束后，让Metis把这个月所有的对地数据包内容密度曲线重新整理了一遍。

她做了一张对比图，把事件爆发前三个月和事件爆发后两个月的数据并排放在一起。

被加权放大后，趋势在图上非常清晰。不只是密度在下降，数据包的结构也在发生变化。医学、社会学、法律、政治方向的内容在减少，而减少的方式不是均匀的缩水，是某些特定议题的定向消失。她能看出来的规律是：凡是涉及争议、凡是包含多方立场、凡是需要读者自己作出判断的内容，都在以一种缓慢但稳定的速度从数据包里退场。

留下来的是什么？

是结论。是已经被处理过的、整齐的、可以直接接收而不需要咀嚼的信息。

她在这张图前坐了很长时间。

陈伯远下午来通讯控制室取一份设备检测报告，顺道看了一眼她的屏幕。

他站在她旁边，把那张对比图看了一会儿。

"事情有点奇怪。"

"怎么了？"

"我不懂脑科学，但是这有点太夸张了。"林晓冬回过头，"三十四万，这是昨天的数据，总共在定义上可以认为是确诊记忆缺失病症的患者。对比一百一十亿的总人口，差不多万分之二点六。"

"这是数据包的对比，社科，哲学，法学，政治，医学，文学。评论学，降幅都在一个点以上。"

"五十倍的杠杆，要是上了股市今天不知道有多少人会跳海。"

林晓冬没有接话，伸了个懒腰放松放松肌肉。

"所以你觉得这不是一个'普通的特殊流行病症'？"

"之前我就不认为，不过现在有点邪门。要不就是联邦瞒报了百分之九十八的患者，或者通信阵列还是统计算法出了两个月的问题没人发现。"

"……"

"思想钢印。"他说，语气像是在陈述一个技术参数。

林晓冬抬起头，"什么？"

"地球那边现在在讨论的技术方案。"陈伯远把检测报告从台面上拿起来，"通过神经刺激强化特定记忆痕迹，阻止记忆被覆盖。从原理上说，它能保住记忆，但代价是人格的僵化，思维模式的固化。"他停顿了一下，"你知道这在说什么吗？"

"什么？"

"如果你把一个人的记忆钉死在某个状态里，你保住的不是他，而是他在那个时刻的一个切片。"陈伯远把报告夹在手臂下，"就像你把那个对比图里，密度最高的那个时间点截下来，冻住，然后告诉所有人这就是正常的。"

林晓冬看着那张图，没有说话。

陈伯远走到门口，停了一下，"我不是在评价这个技术的对错，我只是在描述它的逻辑。"

他走了出去。

林晓冬重新看向屏幕，把那张对比图保存进了一个单独的文件夹。

【第谷基地·新佛罗伦萨区社区服务站·傍晚】

Amara的第二场社区说明会排在下午五点。

来的人比预期多，服务站的小会议室坐不下，临时换到了社区活动大厅。大厅里没有设置麦克风台，Amara站在人群前面，身后是一面空白的投影幕墙。她没有打开任何预设的演示文件。

"我知道大家今天来是为了什么。"她开口，声音不大，但在那个空间里听得很清楚，"我也知道，你们想听到的答案，我可能给不了。但我能给的，我都会说。"

有人问，家属接入通道什么时候正式开放。

她说，目前还没有确定的时间表，因为在开放之前，需要先建立完整的检疫和认知评估标准，确保每一个来到第谷的人，以及已经在第谷的每一个人，都处于可知的安全范围内。

有人问，那个安全范围是什么。

她说，目前还在制定中。

有人问，如果地球那边的情况继续恶化，第谷会不会关闭所有入境通道。

她没有立刻回答，停顿了大约三秒钟。

"第谷是人类在月球上建立的第一座真正意义上的城市，"她说，"它的设计目标从来不是避难所，而是人类文明向深空延伸的前沿。这意味着它有明确的容量边界，有精密的生命保障系统，有需要维护的运行秩序。这些不是冷漠，是第谷能够持续存在的基础。"

她看着台下的人。

"但我也想说另一件事。第谷每一个分区的名字，都是从地球带上来的。新上海，新纽约，新伦敦，新非，新佛罗伦萨。我们不是因为忘记了地球才来到这里，我们是因为想把地球最好的东西带到更远的地方，才来到这里。"她停了一下，"所以这两件事从来不矛盾。我们会尽一切努力保持第谷的安全，同时，我们不会假装地球上发生的事情与我们无关。我们永远是地球的孩子。"

大厅里安静了一会儿。

然后有人问了最后一个问题，是一个坐在角落里、一直没有说话的中年男人，声音很低："如果我的家人在地球那边接受了思想钢印，他们还能申请来第谷吗？"

Amara看着那个男人，看了两秒钟。

"目前的政策文件里，"她说，"还没有对这个问题的明确规定。"

那个男人点了点头，没有再说话。

Amara知道那个点头不是满意，是那种听懂了"还没有规定"背后的意思之后，一个人独自把那个重量接下来的动作。

说明会结束后，她在服务站外站了一会儿。新佛罗伦萨区的走廊墙面上有一幅居民自发绘制的壁画，画的是地球从月球地平线上升起的样子，色彩很鲜艳，笔触很稚拙，像是小孩子画的。但画里的地球是蓝色的，云层是白色的，海洋边界清晰。

不像任何人真正见过的地球，更像一个人对地球的记忆。

傍晚，Amara的办公室还亮着。

第七遍定稿之后，她把那份通告文件发送到了审核队列，等待上级签发。然后她靠在椅背上，把今天Metis整理的各分区情绪监测数据看了一遍。

与家属随迁相关的讨论热度在今天下午达到了入驻第谷以来的单日峰值，各分区的投诉和咨询数量是平日的三点七倍，其中新上海区和新非区的增幅最为显著过去六个小时里，第谷平台上关于"月球隔离"和"地球人员限制入境"的讨论关键词出现了明显的热度抬升。

她在那两个关键词上停留了一会儿。

这是她最担心的那个方向。

失忆症带来的恐惧如果找不到出口，就会开始寻找一个可以指向的对象。如果"外来风险"的叙事在第谷内部成形，这座城市内部的裂缝就不只是"接不接家人"的问题了，而是会演变成一种更持久的、更难处理的对立。

她打开工作记录，在今天的最后一条备注里写下：

"第谷目前的情绪压力已超出常规疏导能力范围。建议在现有信息通报机制之外，建立分区定向沟通渠道，由协调员直接介入各分区社区讨论，提供准确信息，阻断恐惧向对立转化的路径。需要上级授权。"

她看了这段话一遍，觉得还不够，在末尾加了一行：

"时间窗口有限。"

然后她把记录保存，关掉了办公室的灯。

走廊里，第谷的夜间照明已经切换完毕，那种模拟地球夜色的柔和蓝白光从穹顶漫下来，让整条走廊看起来像一个被放大了的、安静的水族箱。

她站在走廊里站了一会儿，没有走。

她在想那份联邦文件的第二部分："积极响应居民的合理人道主义关切。"

合理。

这个词是谁来定义的？

她最终没有想出来一个令自己满意的答案，只是把外套的领子往上拢了拢，走进了第谷的夜里。
