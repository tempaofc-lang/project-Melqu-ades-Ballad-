# 镜公共档案 · 内容维护说明

新增或修改 Markdown 后，推送到 `main`，等待 Actions 中 **Publish Mirror archive** 的 build、deploy 均成功，再刷新网页。已经打开的网页也可切换到其他栏目再返回以重新读取数据。网页不会在阅读中途替换正文。

## 文件夹与命名

| 侧栏 | 文件夹 | 文件名示例 | 当前已迁移 |
|---|---|---|---|
| 人物 / PERSONNEL | `设定集/人物/` | `personnel_01.md` | 01—10 |
| 事件 / INCIDENTS | `设定集/事件/` | `events_01.md` | 01—06 |
| 新闻 / NEWS | `设定集/新闻/` | `news_01.md` | 01—04 |
| 技术 / TECHNOLOGY | `设定集/技术/` | `technology_01.md` | 01—07 |
| 地点 / LOCATIONS | `设定集/地点/` | `locations_01.md` | 01—07 |
| 组织 / ORGANIZATIONS | `设定集/组织/` | `organizations_01.md` | 01—07 |

每个文件是一条档案。按编号数值升序排列，支持超过 99 的编号，允许跳号。编号必须为正整数，`01` 与 `001` 视为重复。只扫描对应文件夹第一层的 `.md` 文件；`README.md` 和以下划线开头的文件会被忽略，其余命名错误会停止构建并显示具体路径。

## 最简新增方式

例如新建 `设定集/人物/personnel_11.md`：

```markdown
# 档案名称

面向公众的介绍正文。第一段会自动成为列表摘要，最多展示一百字。

## 相关记录

后续说明。
```

只需标题和正文，默认无图片、无占位、无档案字段侧栏。复制 `设定集/条目模板/` 中对应模板也可以开始；模板含 `draft: true`，完成后改为 `false` 或删除该行才会发布。

## 可选信息

顶部支持以下简单元数据（不是完整 YAML；每行一个字段，不支持嵌套结构）：

```markdown
---
id: stable-record-name
summary: "列表中的短摘要"
kicker: "资料类别 · 公开档案"
status: "持续更新"
draft: false
---

# 档案名称

## 档案字段

- 身份 / 研究员
- 所属机构 / 广寒宫数据中心

## 正文

面向公众的完整说明。
```

`id` 决定访问地址，省略时使用文件名（不含 `.md`）。已迁移条目保留旧 `id`，请保留它以维持原链接。自定义 `id` 仅用小写英文字母、数字、连字符或下划线，同栏目不得重复。需要改文件编号且保持地址时，也可明确填写原来的 `id`。

`summary`、`kicker`、`status` 均可省略。`title` 可代替一级标题，若二者都写，以一级标题为准。文本含复杂符号时可用双引号包裹（内部双引号写成 `\"`）；布尔值填写 `true` 或 `false`。`## 档案字段` 区域只写 `- 字段 / 内容`，随后用 `## 正文` 或其他二级标题结束。

正文支持段落、二至四级标题、粗体、斜体、行内代码、围栏代码块、单层有序/无序列表、引用、简单 Markdown 表格，以及 `https://`、`http://`、`#/` 链接。表格单元格内不要写竖线。HTML 按文本显示；不支持嵌套列表、脚注、任务列表或正文图片语法。

## 明确需要配图时

将图片放入 `site/assets/`，在条目顶部元数据中添加：

```yaml
image: assets/example.png
image_alt: "图像内容说明"
```

支持 PNG、JPEG、WebP、GIF、SVG、AVIF。路径或文件错误会停止构建。已明确规划图片但暂未制作时，可用 `image_placeholder: true` 和 `image_alt` 显示占位。不写这两类字段即为纯文字。

新闻、技术、纪年的配图功能保持关闭。新闻和技术条目误加图片字段会报错，避免无声忽略。迁移时保留了其他栏目原先明确设置的占位，可按条目删除 `image_placeholder`、`image_alt` 改为纯文字。

## 修改、删除与关于我们

- 修改已有文件会更新对应条目。删除文件会在下次部署时移除条目；旧地址显示“未找到这项记录”。
- `draft: true` 的内容不进入网站输出，可保留未完成文稿。
- 关于我们唯一来源是 `设定集/关于我们/about_us.md`。保留 `# 关于镜 / About Mirror` 与正文分节即可；表格会自动排版。`设定集/about_us.md` 根目录同名副本不参与构建。
- 纪年继续使用 `设定集/联邦大事年纪.md`，格式仍为 `年份 · 简概` 与详细正文。

## 添加新的侧栏栏目

在 `site/sections.json` 增加配置，并创建对应文件夹。填写唯一 `id`、`number`、中文 `title`、英文 `en`、`intro`、`sourceDir`、`prefix`，列表和详情页会自动接入。纯文字栏目可配置 `mediaEnabled: false`。无须修改页面脚本。

## 更新未出现时

先确认修改已推送到 `main`，文件位于上表的目录、不是草稿，再查看对应提交的 Actions。构建失败不会替换线上旧版本；按日志修正格式后重新推送。部署成功后刷新或离开栏目再返回。不要直接编辑 `dist/` 或生成的 `content.js`、`data/catalogue.json`，下次构建会覆盖它们。
