## 一、时代背景

**21 世纪后半叶**，明确年份锚点：2075（福特"拓荒者"出厂）、2076（大卫加沙采访）、**2085（镜一期投用）**、**2087（主线年份）**、2090（第谷 40 万常驻目标）。全球人口约 **110 亿**。

### 社会特征
- **全球基本收入保障计划**：已进入第三阶段，42 亿人受益，月均 **1200 联邦币**；批评者指出这一数字仍远低于发达地区生活成本（"1200 币？在这里连房租都不够"）
- **贫富差距**：最富有的 1% 控制 **48%** 的财富；技术工程师年均 15 万联邦币，传统制造业工人 3 万
- **自动化与就业**：一条生产线从上千名工人缩减到二十人；"效率提高了，但工作机会减少了"
- **气候工程**：海平面每年上升 **2.3 厘米**；太平洋岛国联盟要求海平面控制项目（"我们的家园正在消失"），北美主张大气碳捕获；议会以微弱优势通过等额折中方案
- **AI 治理**：Metis 等 AI 系统在医疗、教育、司法领域广泛应用；伦理监督委员会新指导原则要求涉人类生命与基本权利的决定由人类终审，但偏远地区因缺乏专业人员已依赖 AI 初诊（老医生："医学不只是数据和算法"）
- **世界运行逻辑**：文本明写"这个世界仍按照**加速回报定律**前进着"

## 二、"覆盖"机制（全书核心设定）

### 定义
"覆盖"是一种**作用于量子层面的信息干涉**，不遵循任何已知的能量传递方式——"它就像一个幽灵，直接在现实的底层代码上进行修改"。

### 行为规律
| 属性 | 内容 |
|---|---|
| 作用对象 | **选择性**：“覆盖”修改的内容具有选择性和针对性，耶路撒冷事件展现的“覆盖”只针对冲突、仇恨、创伤类记忆与记录；记录爱、理解、合作的内容毫发无损 |
| 作用方式 | **等量替换，不是删除**。被删的冲突事件被对应的和谐事件取代，且新记忆"带着完整的情感色彩和细节，完美地融入了人们的意识中"（口述录像里老人的口型与全新内容完美吻合） |
| 物理痕迹 | 在微观物质层面留下可检测的痕迹（银盐颗粒异常）；**签名、校验码、时间戳全部不变，只有内容与关系被重排** |
| 扩散方式 | 以事件点为中心向外扩散；耶路撒冷事件一小时内抵达海底基地，最迟五小时覆盖全球；**通信不中断** |
| 宏观指标 | 认知熵总量下降；"认知复杂性指数"关于特定主题急速下跌；地球一致性指数 99.997% → 98.4% → 97.9% |
| 空间边界 | **被地球引力或某种未知的场束缚**——它没有，或者说还没有抵达月球（这是第二～三部的全部前提） |
| 事件类型 | **强遗忘事件**（集中作用，可预测、可观测）／**轻度遗忘事件**（零星先兆） |
| 时间规律 | 强事件之间的时间差**不是线性的**，与几何网格上的角距离有关 |

### 几何结构
全球强遗忘事件的确认位置构成一个**覆盖地球的球面几何网格**（在早期模型中被描述为等边三角形网络）。**高密度节点**即下一次事件的候选点：
- 已确认：日内瓦（CERN）
- 预测并命中：耶路撒冷（97.3%）
- 模型作者：星氷琉璃華（东京大学联合研究组，置信区间 99.7%，附"请勿过度解读"免责声明）

### 关键理论张力
- **它是否有敌意？** 宥理："我们面对的不是常规敌人。我们甚至不知道它是否具有'敌意'。"
- **它是外科医生还是入侵者？** 宥理在最后时刻承认"也许它只是一个仁慈的医生"，但断言"有些病，是不应该被治愈的"；莱山德则说"它比我想象的更……仁慈"——**连它的宗教解释者都误判了它**
- **它是不是人类的适应性进化？** 琉璃華的假说："如果现代社会的信息负荷超过了人脑的处理能力，大脑可能会发展出新的机制来应对……对个体来说是灾难性的，但对物种来说可能不是。自然选择不关心个体的痛苦，只关心物种的生存。"
- **它为什么在大和谐日后停下？** 文本明确留下这个问题："没人知道它为什么停。没人知道它下一次的行动会是什么。"

### 未解之谜
- "它"的本质、来源、目的——**文本全程未明**
- "歌声"：敏感者在强遗忘事件前会听到的、不属于任何已知语言的音节/旋律（秦文是唯一能听见的人）
- 深海黑暗中"似乎有什么巨大的东西在缓缓移动"——"但那可能只是他们的想象"
- 沙漠线中被焚森林遗址里**人为干预痕迹的鳞茎植物**

## 三、三条（后发展到四条）应对路线

| 路线 | 主张 | 代表 | 代价 |
|---|---|---|---|
| **对抗** | 用思想钢印强化记忆，保住人格的连续 | 卡特教授 / FMRC | 人格僵化；"活着的纪念碑" |
| **适应** | 用技术 + 情感网络补足认知功能 | 李明慧 / 均衡会 / 丝计划 | 承认"无法恢复情感记忆"；"虚假的正常" |
| **接受** | 遗忘是恩典，放下即是自由 | 莱山德 / 轮回派 | 文化与历史的整体让渡，且伴随暴力清洗 |
| **不对齐**（第 30 章） | 保留差异，双版本并存，把判断权交回使用者 | 陈伯远 / 林晓冬 | 权威失效；行政后果未知；只能撑 72 小时 |

### 第 30 章提出的第四条路（该节的思想落点）
> "内容、目录、标签、引用关系，都得留下。以前这些是一个系统里相互配合的部分，现在我要防着其中一部分替另一部分作证。"
> "先让使用者知道有差异。原始档案和核查说明一起提供，别替他们选一份，也别把没有查清的部分写成定论。至于他们要不要打那通电话，只能自己决定。"

技术实现：**事件前基准（只读）／观察分支／人工确认区／信任源＝广寒宫本地快照**，配 **72 小时临时保全授权**（隔离层最多 6 小时），本地铯钟时间戳 + 月球本地签名作为唯一可信时间锚。

## 四、月球社会的制度细节（第三部的主要"世界质感"）

| 设定 | 内容 |
|---|---|
| 人工昼光系统 | 每 24 小时循环，模拟地球昼夜节律；色温精确校准（清晨 5600K → 夜晚 3200K 模式），并加入**随机扰动值**以模拟真实天气变化 |
| 重力 | 地球的六分之一；新人需 2–3 周适应，期间步态"像喝了点酒之后的漂浮感"；走廊比地球办公楼更宽 |
| 深空综合征 | 联邦卫生局调查显示长期直视宇宙易引发；广寒宫通讯控制室等地点因此**不设窗户** |
| 人类实勘义务 | 生命保障系统等卫生体系设备的检测必须有人类工程师现场确认（联邦标准） |
| 随迁制度 | 门槛：五年资历 + 18–60 岁；60 岁以上需特别审批，审核周期**九十个工作日起** |
| 资源核算原则 | 只能填"**实际启用容量**"，不得以"规划容量"替代；未完成验收的舱段不得计入 |
| 第谷的生活质感 | 实体资料并不少见——"某些决策需要那种可以用手指翻动、可以在页边空白处随手写字的、独属于纯物理的踏实感" |
| 人际关系 | "更接近一个大型科研机构，而不是一个城市"——大家都很忙，边界清晰 |
|AGI Metis 的角色 | 无处不在的调度与提醒；它的高效本身就是一种压力 |
