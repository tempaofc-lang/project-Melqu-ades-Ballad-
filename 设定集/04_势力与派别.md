## 二、世界联邦政府体系

| 机构 | 职能与文本表现 |
|---|---|
| **世界联邦政府** | 全球治理主体；推行全球基本收入保障计划（42 亿人受益、月均 1200 联邦币）；对记忆危机采取"避免恐慌"的初期方针 |
| **世界联邦议会** | 气候工程预算辩论（太平洋岛国联盟 vs 北美代表团） |
| **联邦卫生部** | 田中美智子所在；主导病例统计、紧急会议、资源调配 |
| **联邦科技部** | 协调研究资金；批准第一期研究预算 |
| **联邦信息部 / 联邦信息局** | 信息管控与新闻整合（地球向月球发送的例行数据包即由联邦信息局整合） |
| **联邦卫生应急委员会** | 危机期发布"语义非常稳定的说明"——"相关研究仍处于验证阶段……请各地居民维持正常生活秩序"。第 28 章第谷人据此得出结论："他们没有否认。" |
| **联邦科学委员会** | 月球线中出现的上级机构 |
| **伦理监督委员会** | 主席玛丽亚·桑切斯；原则：任何涉及人类生命和基本权利的决定都必须由人类做出最终判断 |
| **战略预警局** | "长庚"计划的主管机构；冷战遗留 |
| **联邦军** | 论文书上的模糊军徽、"取火"小队需以色列军方配合（上校接待） |
| **《共识维护条例》** | 后期立法；第四十七条修订被用来掩盖火种计划集会的清除 |

**制度性特征**：这是一个"技术能力极强、决策能力迟钝"的政府——它能建设海底堡垒与月球城市，却在伦理抉择上反复推迟；它能生产极其稳定的官方措辞，却无法回答"哪一部分正常"。

## 三、对抗路线：思想钢印阵营

| 项目 | 内容 |
|---|---|
| 代表人物 | 詹姆斯·卡特教授（哈佛） |
| 载体 | 联邦记忆研究中心（FMRC，千叶县） |
| 技术 | **记忆强化技术（思想钢印）**：通过特定神经刺激模式增强某些记忆的稳定性，靶向海马体与前额叶皮质 |
| 代价 | 人格变化、思维僵化、对强化记忆的过度专注与刻板；001 号案例＝"技巧完美而情感全失" |
| 命名来源 | 星宥理，取自 21 世纪初一篇科幻小说的概念："就像在金属上刻印图案一样，这种技术在大脑中刻印特定的思想模式。被刻印的部分变得坚固，但也失去了灵活性。" |
| 政治动向 | 核心委员会 16:10 通过"暂停推广／保留最高伦理监督下的小规模自愿实验／成立独立副作用评估小组"；卡特带数据出走 |
| 实质 | 文本的定义最锋利——它不是恢复记忆，而是**替患者选择了他遗忘世界的方式**（琉璃華语） |

## 四、适应路线：均衡会

| 项目 | 内容 |
|---|---|
| 代表人物 | **李明慧博士** |
| 口号 | "**适应，进化，生存。**" |
| 组织形态 | 由李明慧文章的支持者自发组成；全球建立**超过三百个"记忆维持中心"** |
| 核心项目 | **"丝"计划**（第一期）：技术 + 情感构成的安全网，AR 辅助记忆 + 志愿者陪护（"核心不是对抗，而是连接"）；**"教育复兴"**；**"方舟计划"**：在耶路撒冷抢做人类记忆的数字化备份（古兰经手稿、希伯来经典、口述历史） |
| 自我认知 | "我们无法阻止记忆的沙漏流逝，但我们可以为每个人编织一张由技术和情感构成的安全网。" |
| 内部争议 | 家属质疑 AR 记忆"不是真正的记忆"、是制造"虚假的正常"；李明慧承认"AR 辅助记忆只能恢复认知功能，无法恢复情感记忆" |
| 与轮回派关系 | 同街竞争同一批绝望的人。轮回派在中心门口"传教"递卡片："为何要修复破碎的牢笼？门本就开着。"均衡会安保不驱赶。 |
| 文本中最好的两句话 | "我们要给人们选择的权利。选择抗争，或者选择接受。" / 事件前夜的全球通告"如果它证明我们完全错了……那么请宽恕我们的愚蠢。" |

## 五、接受路线：轮回派

| 项目 | 内容 |
|---|---|
| 代表人物 | **莱山德·帕克斯**（信众称"使者"，文本以"先知"称之） |
| 标志 | **一个无限循环的柔和螺旋** |
| 标语 | "遗忘是恩典。" / "不要执着于过去，那里没有出路。" / "我们已经被净化。" / "平和即是力量，遗忘方得新生。" |
| 教义核心 | 遗忘是"主"的恩典与"轮回"；是"宇宙的慈悲"，是"伟大的意志在为我们施行一场灵魂的外科手术"；它在"切除我们名为'自我'的肿瘤" |
| 仪式 | 同心圆牵手闭目站立、夜祷（设"精神医学导师"现场指导）、"和平律"诵读、儿童诵念 |
| 社会工程 | 智能旅馆每天上午九点播放"思想卫生提示"；智能终端提示"思维温度偏低，请参与明日晨间感知操练"；博物馆改名换展；《共识维护条例》 |
| 信众构成 | 不只绝望的底层民众，还有厌倦现代科技与信息过载的社会名流、艺术家、哲学家——"他们认为莱山德提供了一种后现代的灵性解脱方案" |
| 暴力面 | 火种计划第一次集会全员被清除；"清理掉他们"；次日新闻只播条例修订，"那群人从未存在过" |
| 结局状态 | "以一种温和而不可抗拒的方式接管了世界的大部分社会结构"；而"它"暂时停下脚步，"没人知道它为什么停" |

## 六、观测路线：普罗米修斯计划

| 项目 | 内容 |
|---|---|
| 主导者 | 星宥理、星氷琉璃華 |
| 批准 | 联邦政府地下十二层"方舟"会议（机密文件随后经暗网泄露，全球震动） |
| 基地 | 太平洋海底 1300 米 **普罗米修斯基地** |
| 座右铭 | "**不知山之高远，唯知其必行。**"（不同章节亦作"不知山之高远，唯知其必行"／琉璃華在早期与父亲的对话中说过"不知道山有多高的时候，按照最坏的打算"） |
| 任务 | **破译、预测、接触**——不是战斗 |
| 编制 | 计算组、观测组；下属**"取火"小队**（12 人，携量子场探测器） |
| 方法论 | 几何网格拟合、人口密度矢量加权、信息熵局部突变模型、**信仰密度算法**、全球信息密度图谱 |
| 对战果 | 成功预测 CERN 事件与耶路撒冷事件（97.3%），但**未能阻止、未能理解** |
| 终局 | 耶路撒冷事件后失联；发出四分钟全球广播；"我们会回来，只要你们还能燃起火种。" |

## 七、残余抵抗：火种计划

| 项目 | 内容 |
|---|---|
| 性质 | 敏感者建立的加密通讯网与组织 |
| 目标 | 组织正式成立 + 探讨记忆恢复的可能性 |
| 结局 | 第一次集会当晚被清除（三声枪声 + "所有人脑组织损坏，没有人存活"），次日新闻无报道 |
| 遗留 | 四分钟广播；"若记忆无法存续，爱是否还存在？"；匿名节点**工蜂／守林人／档案员**；**长庚-7** |
| 关键概念 | **敏感者**——"你们无法被完全覆盖，这就是你们的意义"，但原因"我们没能理解为什么" |
