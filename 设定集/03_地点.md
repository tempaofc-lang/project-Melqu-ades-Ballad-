## 三、月球 · 第谷基地（正面）

月球第谷陨石坑一带的大型定居城市，人工昼光系统每 24 小时循环一次，居民生理时钟以地球节律校准；重力为地球的六分之一。

| 分区/设施 | 描述 |
|---|---|
| **新上海区** | 街道按上海外滩比例关系设计，用城市峡谷光影与穹顶弧度模拟天空曲率；含环境工程部、居住舱群 B-17 层与 C 区气密走廊、东侧三号公共中庭、社区厨房、大学城 |
| **新纽约区** | 更明亮、广告幕墙与投影招牌密集，服务大厅承担家属通讯、航班询问等窗口 |
| **新伦敦区** | 出现物流公司 |
| **新莫斯科区** | 与新上海区之间曾有公共走廊使用权纠纷（峰值重叠率 67%） |
| **新佛罗伦萨区** | 社区议事会、信息协调署 |
| **新非区** | 农业实验舱；Amara 的社区服务辖区之一 |
| **新南极区** | 实验舱扩建、外圈维护站 |
| **行政中枢** | 卡里姆·纳塞办公室与会议室所在地 |
| **第谷轨道港** | 地月运输窗口、太阳风等级、外圈维护机械臂检修计划 |
| **第谷综合大学** | 没有校门；课堂上公开 FMRC 的"思想钢印"001 号案例 |
| **第四期居住舱** | 一部第 2 章说已与主体结构对接、可额外容纳约七万人；第 30 章相关栏位仍空着，未通过验收不得计入"可用安置人数" |

## 四、月球 · 广寒宫（背面）

月球**背面**科研基地，常驻科研及工业人员 **5327 人**（大和谐日前最后一次公开数据）。从地球方向永远看不到，也因此成为覆盖之外的信息孤岛。

| 设施 | 描述 |
|---|---|
| **通讯控制室** | **没有窗户**（月球背面开窗只能看到宇宙，且长期直视宇宙易引发"深空综合征"）；三个监控界面：对地链路、深空监听频段、基地内部通讯网络。对地链路常态：S 波段 −118 dBm，X 波段 −121 dBm |
| **镜数据中心 · 核心机房** | 温度恒定 18℃、湿度 40%、导电橡胶地板；每台机柜独立状态监控，Metis 以毫秒采样。**镜系统核心存储阵列**所在 |
| **公共餐厅 / 中央廊道 / 办公室** | 日常生活空间；中央廊道是第 30 章"交班后停下看消息"的场所 |
| **外环通道** | 有气密观察窗，可见月背地表与不受地球光污染遮蔽的高密度星空 |
| **广寒宫运营委员会** | 签发 72 小时临时保全授权的机构 |

### 镜（元宇宙）
- 月面对地球**一比一映射、永不离线的数字备份**；**2085 年**一期服务器阵列投用
- 内容：人类历史上所有被数字化的文化遗产——所有语言、艺术、科学文献、争论、矛盾、噪声（秦文语："如果有外星人想了解人类，把这个阵列给他们看就够了"）
- 独立运营；**物理链路与地球联邦网络隔离**；采用点对点激光通讯
- 第 30 章的双版本机制：事件前基准（红色，只读）／观察分支（蓝色）／人工确认区／信任源＝广寒宫本地快照

## 六、地点命名规律（供后续写作保持一致）

- **月球地名**：一律以地球城市/地区名冠以"新"字（新上海区、新纽约区、新伦敦区、新莫斯科区、新佛罗伦萨区、新非区、新南极区）——对应"月面是对地球的复制"这一主题
- **基地命名**：第谷（月面城市，以月面地貌命名）／广寒宫（月背基地，中国古典月宫意象）——两者共同构成"科学—神话"的双重命名
- **中国意象密集处**：普罗米修斯基地座右铭"不知山之高远，唯知其必行"、长庚-7（长庚＝金星古名，主预警）、鹊桥（中继）、广寒宫、安隅、午后
