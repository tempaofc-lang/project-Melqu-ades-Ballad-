## 二、一句话故事

2087 年，全球出现无法解释的选择性记忆丧失；人类发现这不是疾病，而是一种名为**"覆盖"**的高维信息干涉力量，它系统性地**重写**一切关于冲突、仇恨与创伤的记忆。当它以"耶路撒冷强遗忘事件"把全世界的历史换成温情版本后，唯一未被覆盖的月球背面基地"广寒宫"，成为人类原始记忆的最后副本——而地球上最后一个还"记得"的人，用一座冷战废弃射电望远镜，向月球发出了求援的信号。

## 三、三部分结构

| 部分 | 章节 | 主线 | 主角视角 |
|---|---|---|---|
| **第一部 · 遗忘** | 第 1–13 章 | 东京发现病例 → 联合研究 → 思想钢印伦理之争 → 普罗米修斯计划 → 预测并见证"覆盖"降临耶路撒冷 | 星宥理、星氷琉璃華、宰秦文 |
| **第二部 · 余烬** | 第 14–22 章 | 被"覆盖"后的世界（大和谐日）→ 火种计划覆灭 → 敏感者残存 → 穿越中亚唤醒"长庚-7" → 向月球发送请求 | 宰秦文、大卫·科恩 |
| **第三部 · 镜** | 第 23–30 章 | 月球双基地（第谷基地 / 广寒宫）群像日常 → 记忆缺失升级为全球事件 → 观测耶路撒冷事件 → 建立"双版本历史"，拒绝与地球对齐 | 郑永年、林晓冬、陈伯远、Amara |

**阅读顺序 ≠ 时间顺序**（重要）：

- 第三部开篇第 23 章的时间锚点是 **2087 年 3 月 14 日**，即第一部第 2 章（3 月 15 日新闻）的**前一天**；
- 第三部第 28–29 章的"耶路撒冷事件"，与第一部第 12–13 章的强遗忘事件**同为一事**，只是从月球侧旁观；
- 第二部（第 14–22 章）发生在耶路撒冷事件**之后数月**（大和谐日已过）。
- 因此全书实际时间轴为：**第 23–30 章 ≈ 第 1–13 章（同期双线）→ 第 14–22 章（后续）**，而结尾停在第 30 章"事件后第六小时"，待更新中。

## 四、核心名词速查

| 名词 | 一句话解释 |
|---|---|
| **覆盖** | 作用于量子层面的信息干涉，直接改写现实底层记录与人的记忆；不是删除，是**等量替换** |
| **强遗忘事件** | "覆盖"的一次集中作用，短时间内使人丧失一整类高度结构化记忆，可在宏观层面造成改变 |
| **轻度遗忘事件** | 覆盖的零星先兆，个体级别 |
| **认知熵 / 认知复杂性指数** | 人类文明信息熵总量；覆盖使其系统性下降 |
| **敏感者** | 无法被完全覆盖的极少数人，是"最后的桥梁" |
| **思想钢印** | 通过神经刺激强化特定记忆回路的稳定性的技术；代价是人格僵化。命名取自 21 世纪初科幻小说概念 |
| **镜（元宇宙）** | 月面对地球一比一映射、永不离线的数字备份；**2085 年**一期投用，独立运营、物理链路与地球隔离、点对点激光通讯 |
| **鹊桥** | 月球轨道中继网络，节点如 7-Delta、12-Alpha；大和谐日后大部分关停但未销毁 |
| **广寒宫** | 月球背面科研基地，常驻 5327 人（大和谐日前数据）；镜数据中心所在 |
| **第谷基地** | 月球正面（第谷陨石坑）大型定居城市，人工昼光系统、六分之一重力，设七个分区 |
| **Metis** | 贯穿全球与月球的 AI 辅助系统，承担调度、归档、建议、简报生成 |
| **长庚-7** | 冷战遗留的"全天境战略预警射电望远镜阵列"之一，位于塔克拉玛干沙漠 |
| **大和谐日** | 覆盖全球扩散后被命名的那一日；此后世界以"和谐"为官方历史 |
| **火种计划** | 敏感者建立的加密通讯网与组织；首次集会即被"清理"，仅余广播残响 |
| **事件前基准 / 观察分支** | 广寒宫的"双版本历史"机制：红色只读基准 + 蓝色观察分支 + 人工确认区 |
