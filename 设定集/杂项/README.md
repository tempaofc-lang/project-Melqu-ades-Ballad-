# 杂项内容维护

第八栏：杂项 / MISCELLANEOUS。

复制 `_Miscellaneous_模板.md` 并命名为 `Miscellaneous_001.md` 即可新增条目。后续使用 002、003 等编号，至少三位、正整数，按编号排序。前缀大小写须一致。以下划线开头的模板不会发布。

格式为一个 `# 大标题`，随后三个 `## 小标题`，每个小标题下写非空正文。小标题名称完全自由，连“正文”“档案字段”在本栏目也只是普通标题，不是特殊标签。无需填写 tag 或元数据。

本栏目纯文字，不设图片或图片占位。默认地址如 `#/miscellaneous/miscellaneous_001`（文件名前缀保留大写，网页 id 转为小写）。推送到 main 后自动构建，部署成功后刷新或离开栏目再返回即可读取更新。

完整接口和可选摘要/草稿元数据见[仓库 README](../../README.md)。
