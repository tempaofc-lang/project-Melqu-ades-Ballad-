# 杂项内容维护

复制 `_Miscellaneous_模板.md`，命名为 `Miscellaneous_001.md`，后续编号 002、003 等。编号至少三位，前缀 M 大写；模板以下划线开头，不公开发布。

```markdown
# 大标题

## 小标题一
## 小标题二
## 小标题三

统一正文第一段。

统一正文第二段。
```

三个小标题是大标题下方同一行的三项自由文本，不是三个章节；源文件分行书写，网页并排显示，手机上各项内部可换行。不要在三个小标题之间插入正文，也不要要求每项分别有正文。第三个小标题后直接填写完整正文。

不需要固定 tag；标题可任意命名，包括“正文”“档案字段”。没有图片、占位或档案字段侧栏。可选摘要只用于列表，不在详情页重复展示。

默认网页地址为 `#/miscellaneous/miscellaneous_001`。推送到 main 后自动构建，部署成功后刷新或重新进入栏目读取更新。完整接口见[仓库 README](../../README.md)。
